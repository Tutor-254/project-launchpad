## Understanding Competencies

### What is a Competency?

A **competency** is a concrete skill you'll be able to **do** after the course. It's more specific than a course title.

**Example Competencies:**
- "Deploy a Node.js API to AWS"
- "Design normalized database schemas"
- "Conduct user research interviews"
- "Implement CI/CD pipelines"

Each competency has:
- **Observable behaviors**: Specific actions you'll perform (e.g., "Set environment variables securely")
- **Success criteria**: How you'll be evaluated (knowledge test + project)
- **Related jobs**: Entry-level roles using this skill

### Why Competencies?

✅ **Clarity**: You know exactly what you'll be able to do  
✅ **Flexibility**: Skip content you already know  
✅ **Credibility**: Badges prove actual skills to employers  
✅ **Relevance**: Understand why each topic matters for your career

## The Diagnostic Assessment

### What is It?

A **diagnostic assessment** is a short quiz (5-10 questions) that tests your baseline knowledge **before** the course starts.

### Why Take It?

Your score determines your **personalized pathway**:

- **Score < 50%**: We'll recommend starting with prerequisites or foundational content
- **Score 50-70%**: You'll start with the main course material, with some review resources
- **Score ≥ 70%**: You can skip basics and jump to advanced topics

### Taking the Diagnostic

1. **Before enrolling**, you'll see: *"Take Diagnostic Assessment"*
2. **Click to start** (typically 15-30 minutes)
3. **Answer questions** honestly—there's no penalty for "wrong" answers
4. **Get results** including:
   - Your score
   - Recommended pathway
   - Optional prerequisite courses or modules
   - Starting point in this course

### Important Notes

- ✅ Diagnostic is **free** and counts toward enrollment
- ✅ You'll see **your score and recommended path**
- ✅ You can **retake** the diagnostic after **7 days** if you improve
- ❌ Diagnostic score does **not** impact your final grade
- ❌ Cannot start main course content until diagnostic is complete

```
│   • Module 1: Node.js Basics             │
│   • Module 2: HTTP Introduction          │
│                                          │
│ 📚 Optional Review:                      │
│   • Remediation: Asynchronous JS         │
│                                          │
│ 🎯 Time Estimate: 40 hours               │

```

### Understanding Your Pathway

| Element | Meaning | Action |
|---------|---------|--------|
| **Baseline Competencies Met** | You have these skills already | Skip if you're confident |
| **Recommended Start** | Start here for fastest progress | Begin with this module |
| **Sections You Can Skip** | Content matching your baseline | Safe to skip (or review) |
| **Optional Review** | Suggested remediation if needed | Check if you want reinforcement |
| **Time Estimate** | Personalized based on your path | Budget accordingly |

### Using Your Pathway

1. **Review the recommendations** (take 5 min to understand)
2. **Start with recommended module** (no need to go in order)
3. **Check optional reviews** (helpful if you hit trouble later)
4. **Skip marked sections** (you can revisit later if needed)

## Mastering a Competency

### The Mastery Cycle

Each competency follows this cycle:

```
1. Learn
   └─ Video lectures, readings, examples

2. Assess
   └─ Knowledge test (multiple choice, typically 10 questions)
   └─ Pass: ≥70% correct
   └─ Fail: Remediation offered before retry

3. Project
   └─ Build something real (API, design, business plan, etc.)
   └─ Submit: File, GitHub link, or video demo

4. Review
   └─ Instructor grades your project
   └─ Feedback provided (within 3-5 days typical)

5. Badge (if passed)
   └─ Earn competency badge when assessment + project ✓
```

### Taking an Assessment

1. **Study the lecturesfor the competency
2. **Review assessment tips** (if provided)
3. **Click "Take Assessment"** when ready
4. **Answer questions** (can't go back)
5. **Get results**:
   - ✅ **Passed**: Ready for project; see next steps
   - ❌ **Failed**: See failing topics + optional remediation
     - Required video: Review remediation (if flagged)
     - Recommended retry: After 24 hours (default cooldown)

### After Failing an Assessment

1. **Review feedback**: Which topics struggled?
2. **Watch remediation video** (usually 15-30 min) — **if required**
3. **Study those specific topics** in lectures
4. **Retry after cooldown** (typically 24 hours)
   - You have max 3 attempts typically
   - After each retry, cooldown resets

### Submitting a Project

Once assessment is **passed**:

1. **Read project brief** (what to build/create)
2. **Review rubric** (how you'll be graded)
3. **See example** (reference solution or showcase)
4. **Build/create your project** (take your time; no deadline)
5. **Submit** via:
   - **File upload**: ZIP, PDF, CSV, etc.
   - **URL**: GitHub repo, deployed site, Google Doc link
   - **Video**: Screen recording (~5-10 min typical)
6. **Wait for feedback** (3-5 days typical)
   - Instructor grades using rubric
   - You'll receive score + comments

### Project Tips

✅ **Do**:
- Read brief + rubric carefully before starting
- Check example submission to see quality bar
- Implement all required features
- Add clear documentation
- Submit your best work (no penalty for resubmitting if not graded yet)

❌ **Don't**:
- Copy example solutions exactly
- Skip documentation ("code is self-documenting")
- Submit without testing
- Miss the due date (if any)—submit early

## Earning Badges

### When Do You Earn a Badge?

A badge is earned when **BOTH**:
- ✅ Assessment passed (≥70%)
- ✅ Project graded + passed (rubric score ≥70%)

**You need BOTH to get the badge.** One alone doesn't count.

### Badge Details

Each badge includes:
- **Competency title**: The skill you proved
- **Your name**: Earner
- **Date earned**: When both requirements met
- **Badge code**: Unique verification number
- **Badge image**: Shareable graphic

### Viewing Your Badges

1. **Profile → Competency Profile**
2. See all badges earned
3. Download as PDF, share links, export to LinkedIn, Twitter

### Badge Verification

Each badge is **publicly verifiable**:

**Your badge link**: `https://arcane.example.com/verify/badge/BADGE-a1b2c3d4-1672531200`

Anyone can visit to verify:
- Your name + competency
- Date earned
- Related job titles
- Your project evidence (if you shared it)

## Building Your Portfolio

### What's a Portfolio?

Your **portfolio** is your collection of competency badges + project evidence. It's:
- **Public** (optional): Share with employers, LinkedIn, Twitter
- **Private** (default): Only you see it

### Creating Your Portfolio

1. **Profile → Competency Profile**
2. **View Your Badges**: All badges you've earned
3. **Make Portfolio Public** (toggle):
   - Includes all badges + competencies you've completed
   - Shows related job titles (employers see what you can do)
   - Displays your submitted projects (if you opt in)
4. **Share Your Profile Link**:
   - `https://arcane.example.com/profiles/yourname`
   - Share on LinkedIn, Twitter, email, resume

### Portfolio Sharing Options

| Platform | What Happens |
|----------|--------------|
| **LinkedIn** | Badge + link posted to your feed; auto-formats |
| **Twitter** | Tweet with badge image + link; customize message |
| **Email** | Link sent to friends/network; pre-composed message |
| **Shareable Link** | Copy URL to paste anywhere (resume, portfolio site) |

### Privacy Settings

- **Badge visible**: Yes (always public once earned)
- **Project evidence visible**: You choose (private by default)
  - "Keep private": Only you see your project
  - "Show in portfolio": Anyone visiting your profile sees project
- **Full portfolio public**: You choose (private by default)
  - "Public": Everyone can see all your badges + competencies
  - "Private": Only you can see your profile

## Tips for Success

### 1. Understand Your Pathway

- ✅ Read the pathway recommendation after diagnostic
- ✅ Understand why certain sections are recommended
- ✅ Feel free to review skipped sections if interested

### 2. Study Actively

- ✅ Take notes on key concepts
- ✅ Pause videos to practice code
- ✅ Try examples before reading solutions
- ❌ Don't just watch passively

### 3. Prepare for Assessments

- ✅ Review lecture notes before taking test
- ✅ Understand why each answer is correct (not just memorize)
- ✅ Check that you can explain concepts to someone else
- ❌ Don't cram night before; spread study over days

### 4. Invest in Projects

- ✅ Treat projects as portfolio pieces
- ✅ Add features beyond minimum requirements (impress!)
- ✅ Document your code and design decisions
- ✅ Deploy/submit your best work
- ❌ Don't treat projects as "just something to submit"

### 5. Engage with Feedback

- ✅ Read instructor comments carefully
- ✅ Understand gaps between your work + rubric expectations
- ✅ Apply feedback to next competency
- ✅ Ask questions if feedback unclear

### 6. Manage Your Time

- ✅ Check pathway estimate (e.g., 40 hours)
- ✅ Work steadily (2-3 hours/week = 5-6 months for full course)
- ✅ Start projects early (don't wait for last minute)
- ❌ Don't wait to do everything at once

### 7. Share Your Progress

- ✅ Share badges on social media as you earn them
- ✅ Show your portfolio to peers
- ✅ Use portfolio link when applying for jobs
- ✅ Celebrate milestone badges (3 earned = ~50% through course!)

## FAQ

### Q: What if I score poorly on the diagnostic?
**A**: Your pathway will include more foundational content. That's fine! The diagnostic is not graded—it's just to help you learn efficiently. You can retake after 7 days if you want a different pathway.

### Q: Can I skip my recommended starting section?
**A**: Yes, but not recommended. The pathway is personalized to your score. If you skip and struggle, you can revisit.

### Q: What if I fail an assessment?
**A**: You'll see which topics you struggled with. There's a remediation video (optional or required, depending on setting). You can retry after cooldown (24-48 hours typical).

### Q: Do I have unlimited retries?
**A**: No, max 3 attempts typically. After 3 fails, you'll need to revisit the content and submit a support ticket. The goal is mastery, not passing.

### Q: What if I can't finish a project in time?
**A**: There's no hard deadline in most courses. Submit whenever ready. If a deadline exists (special cohort), contact your instructor for extension options.

### Q: How do employers verify my badges?
**A**: Each badge has a public verification link. Employers can visit `https://arcane.example.com/verify/badge/[code]` and see your competency + date earned + project evidence (if shared).

### Q: Can I download badges to use offline?
**A**: Yes! From your profile, click "Export" to download badge images + portfolio as PDF.

### Q: What if I earn the same competency in multiple courses?
**A**: Each course = separate badge instance. You can display all on your portfolio. Employers see breadth of study across courses.

### Q: Can I share my portfolio without my projects?
**A**: Yes. Badges alone are valuable. You decide whether to include project evidence in your public portfolio.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Can't take assessment | Check: (1) completed all lessons?, (2) any system error? Try refreshing. |
| Can't submit project | Likely cause: assessment not yet passed. Pass assessment first. |
| Cooldown timer won't reset | Remediation may be required. Check assessment feedback. Complete video, then retry. |
| Badge not showing in profile | Wait 1-2 min for page to refresh. If still missing, contact support. |
| Portfolio link not working | Check: (1) portfolio is set to "Public", (2) copy link exactly, (3) try incognito browser. |
| Instructor feedback unclear | Reply to feedback or contact instructor via course Q&A. |
