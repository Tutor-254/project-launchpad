                           AVAILABLE FUNCTIONS
================================================================================

generateAssessmentQuestions(title, description, count)
  → Auto-generates multiple choice questions from competency description
  → Returns: questions array with options, answers, explanations
  → Use: Instructor creates competency → AI generates questions

generateSubmissionFeedback(competency, rubric, submission, maxLength)
  → Generates intelligent feedback on student work
  → Returns: personalized feedback text
  → Use: Student submits project → AI provides feedback

generateLearnerPathway(name, completed, available, goals)
  → Recommends personalized learning path
  → Returns: next competencies, rationale, estimated duration
  → Use: After diagnostic → AI recommends path

generateCourseImprovements(title, description, topics)
  → Suggests course enhancements
  → Returns: new topics, improvements, assessments, strategies
  → Use: Instructor reviews course → AI suggests improvements

generateContent(prompt, options)
  → Generic content generation
  → Returns: generated text with metadata
  → Use: Custom AI tasks
